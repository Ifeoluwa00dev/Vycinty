
# Vycinty 📍

### Discover Local Businesses in Ile-Ife, Nigeria

**React • TypeScript • Tailwind CSS • Supabase • PostgreSQL**

Vycinty is a local business discovery platform designed to help residents and visitors in Ile-Ife, Nigeria, find businesses, services, and experiences within their community.

The project aims to make local businesses more discoverable through a centralized, searchable, and mobile-friendly digital platform.

---

## 🌍 The Problem

Many small businesses in Ile-Ife depend heavily on word of mouth, physical visibility, and social media to reach customers.

Finding a particular service, shop, or business can be difficult when information is scattered across different platforms.

Vycinty explores a more organized approach to local business discovery.

---

## 💡 The Solution

A digital business directory where users can discover businesses by name, category, or location, while business owners can establish an online presence.

The goal is to make local commerce easier to discover and navigate.

---

## ✨ Core Features

### 🔎 Business Discovery

- Search for local businesses by name
- Browse businesses by category
- Explore businesses based on location
- Find relevant services and experiences

### 🏪 Business Profiles

Business listings can present:

- Business names and descriptions
- Contact information
- Operating hours
- Available services
- Business photographs

### 👤 Business Management

- Business listing functionality
- Business owner account workflows
- Business profile management

### 📱 Mobile-First Experience

- Responsive layouts
- Mobile-friendly navigation
- Accessible browsing experience
- Interfaces designed for smaller screens

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Required Supabase and Neon configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ifeoluwa00dev/Vycinty.git
   ```

2. Navigate into the project:

   ```bash
   cd Vycinty
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the environment variables required by the application.

   Refer to the project's source code or environment template for the exact variable names.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local development URL shown in your terminal.

> Some features may require configured authentication, database access, or external services.
